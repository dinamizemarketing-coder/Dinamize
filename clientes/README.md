# Clientes — fontes para o High Copy

Cada pasta reúne o material de um cliente, levantado do Google Drive, do Gmail e de páginas públicas:

| Arquivo | Conteúdo |
|---|---|
| `dossie.md` | Perfil do cliente: o que faz, público, tom de voz, regras, formatos, campanhas, histórico e lacunas |
| `referencias.md` | Textos reais (planejamentos, legendas, roteiros, feedbacks) para usar como referência de copy |
| `fontes.md` | Lista de todas as fontes com link |
| `high-copy.md` | Descrição do negócio usada para gerar os setups no High Copy |

| Pasta | Projeto no High Copy |
|---|---|
| `agencia-2ks/` | Agência 2Ks |
| `agesan-rs/` | AGESAN-RS |
| `trt-14/` | TRT-14 |
| `finatec-ocean/` | FINATEC-OCEAN (setups Samsung Ocean Brasília + FINATEC institucional) |
| `go-boost/` | GO BOOST |

Os dossiês contêm nomes e e-mails de contatos dos clientes: revise antes de compartilhar fora da agência.
